# แชทติดต่อแอดมิน

ผู้ใช้ที่เข้าสู่ระบบจะมีปุ่ม “ติดต่อแอดมิน” ลอยมุมขวาล่าง ผู้ดูแลมีปุ่ม “กล่องข้อความ” พร้อมรายการห้องของผู้ใช้ แอดมินทุกคนใช้กล่องข้อความร่วมกันและเห็นสถานะอ่านร่วมกัน

ข้อความตัวอักษรยาวไม่เกิน 2,000 ตัวอักษร เก็บใน PostgreSQL ตาราง `chat_rooms` และ `chat_messages` ปิดหน้าต่างหรือออกจากระบบแล้วประวัติยังอยู่ โหลดครั้งละ 50 ข้อความ และกดโหลดข้อความก่อนหน้าได้ ข้อความไม่รองรับ HTML หรือไฟล์แนบ

ส่งผ่าน API ที่ตรวจ token บัญชีที่ยังใช้งาน และสิทธิ์เจ้าของห้องทุกครั้ง เมื่อบันทึกสำเร็จ ระบบส่ง SSE แจ้งว่ามีข้อมูลแชทเปลี่ยน โดยไม่มีเนื้อหาหรือรหัสห้องใน event หน้าเว็บจึงเรียก API เพื่อโหลดเฉพาะข้อมูลที่มีสิทธิ์ดู มีการตรวจข้อมูลสำรองทุก 15 วินาทีเมื่อหน้าเว็บเปิดอยู่

สถานะอ่านจะอัปเดตเฉพาะเมื่อเปิดห้องและหน้าเว็บมี focus โดยบันทึกถึงรหัสข้อความที่โหลดแล้ว ข้อความเข้ามาภายหลังจะยังเป็นข้อความที่ไม่ได้อ่าน

เมื่อเริ่มเซิร์ฟเวอร์ผ่าน `npm start` ระบบจะใช้ migration `013_admin_chat.sql` อัตโนมัติ สำหรับ Docker ต้องสร้าง image ฝั่ง app ใหม่เพราะมีโค้ด server และ migration เพิ่ม:

```powershell
docker compose up -d --build app
```

ทดสอบฐานข้อมูลใน temporary tables ภายใน transaction ที่ rollback เมื่อจบ:

```powershell
$env:DB_INTEGRATION='1'
node --test test/chat.integration.test.js
Remove-Item Env:DB_INTEGRATION
```

ตรวจหน้าเว็บด้วย Playwright (ต้องมีแพ็กเกจ `playwright` ให้ Node โหลดได้):

```powershell
node scripts/check-chat-ui.js
```

ตั้ง `CHAT_BROWSER_PATH` หากต้องการใช้ executable ของ Chromium ที่มีอยู่ และ `CHAT_SCREENSHOT_DIR` หากต้องการบันทึกภาพหน้าจอ สคริปต์ทดสอบใช้ temporary tables และ rollback เช่นเดียวกัน

กล่องแชทปรับตำแหน่งตามพื้นที่จอที่มองเห็นจริง (`VisualViewport`) และขนาดเมนูล่าง บนคอมพิวเตอร์อยู่ใกล้มุมขวาล่าง บนมือถือเปิดเหนือเมนูล่างพร้อมซ่อนปุ่มเปิดชั่วคราว ในพื้นที่จอเตี้ยจะย่อส่วนหัวและรายการห้องเพื่อรักษาพื้นที่ช่องพิมพ์ การตรวจหน้าจอครอบคลุม 16 ขนาดตั้งแต่ 280 ถึง 1920 พิกเซล รวมแนวนอนและการจำลองพื้นที่ที่เหลือเมื่อเปิดคีย์บอร์ด
