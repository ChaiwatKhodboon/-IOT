# ดูข้อมูลยืม–คืนใน PostgreSQL / pgAdmin

ตาราง `loans` เก็บอุปกรณ์ที่ยืมไว้ใน `equipment_id` ซึ่งอ้างอิง `equipment.id`
และเก็บบัญชีผู้ยืมใน `user_id` ซึ่งอ้างอิง `users.id` ชื่ออุปกรณ์จึงไม่ได้เป็นคอลัมน์ในตาราง `loans` โดยตรง

เปิด **Schemas → public → Views → loan_details → View/Edit Data → All Rows**
ใน pgAdmin หากยังไม่เห็น ให้คลิกขวาที่ Views แล้วเลือก Refresh หรือใช้ Query Tool:

```sql
SELECT * FROM public.loan_details ORDER BY borrowed_at DESC, loan_id DESC;
```

มุมมองนี้รวมรหัสและชื่ออุปกรณ์ หมวดหมู่ จำนวน ชื่อผู้ยืม ชื่อบัญชี รหัสนิสิต
วันที่ยืม กำหนดคืน วันที่คืน สถานะ สภาพตอนคืน วันที่แจ้งปัญหา
วันที่ซ่อมเสร็จ สถานะซ่อม และหมายเหตุทั้งการยืมและการคืน
ข้อมูลเปลี่ยนตามตารางต้นทางโดยอัตโนมัติ ไม่ต้องคัดลอกหรือซิงก์รายการใหม่
ใช้มุมมองนี้อ่านรายงาน และแก้ไขรายการผ่านระบบตามเดิม

- `borrower_name` ใช้ชื่อที่กรอกตอนยืม หากรายการเดิมไม่ได้เก็บไว้ จะใช้ชื่อเจ้าของบัญชีปัจจุบัน
- ชื่อ รหัส และหมวดหมู่อุปกรณ์เป็นข้อมูลปัจจุบันจากคลัง ไม่ใช่สำเนาชื่อ ณ วันที่ยืม
- `issue_reported_at` อิงวันที่คืน หรือวันที่ยืมสำหรับรายการที่มีหมายเหตุและยังไม่คืน ตามหน้าซ่อมบำรุง
- `repaired_at` ว่างหมายถึงยังไม่มีการบันทึกซ่อมเสร็จ ระบบไม่สร้างวันที่ย้อนหลังขึ้นเอง
- ระบบเดิมไม่ได้บันทึกผู้ที่นำอุปกรณ์มาคืนแยกจากผู้ยืม จึงไม่สามารถยืนยันตัวผู้คืนจริงจากข้อมูลย้อนหลังได้

ตัวอย่างคำสั่งแยกรายการที่กำลังยืมและประวัติซ่อมอยู่ใน `database/loan-report.sql`

## ฐานข้อมูลเดิม

รันไฟล์ `database/migrations/010_loan_details_view.sql` กับฐานข้อมูลที่แอปใช้งาน
ไฟล์นี้เพิ่มเฉพาะคอลัมน์ที่ยังขาดและสร้าง/ปรับมุมมอง สามารถรันซ้ำได้
สำหรับฐานข้อมูลใหม่ `database/schema.sql` มีมุมมองนี้อยู่แล้ว
ไม่ต้องรัน `db:init` กับฐานข้อมูลที่มีข้อมูลอยู่
